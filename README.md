# BluePeak sample site (React + Vite)

A fictional company-site preview built with React, Vite, React Router, and mobile-first CSS. Product descriptions,
metrics, customer names, locations, and credential badges are placeholders and must be replaced with verified details
before publication.

## Install and run

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Structure

```text
src/
  components/  Header, Navigation, Footer, Button, Logo, and shared UI
  sections/    Home-page sections and reusable page content
  pages/       Home, About, FAQ, and NotFound
  layouts/     Shared header, demo notice, and footer
  data/site.js Placeholder content and navigation
  styles/      Global design tokens and component styles
public/        Favicon, robots.txt, sitemap.xml
```
